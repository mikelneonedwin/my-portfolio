# Next.js Portfolio with Admin Dashboard

## Overview

This project is a modern, responsive portfolio website built with Next.js, featuring an admin dashboard for easy content management. It showcases your projects, skills, and professional information while providing a secure way to update content.

## Features

- Responsive design for optimal viewing on all devices
- Dark mode support
- Server-side rendering and static site generation for improved performance
- Dynamic project pages with admin-editable content
- Secure authentication system for admin access
- Firebase integration for data storage and authentication
- Custom middleware for route protection

## Tech Stack

- [Next.js 13](https://nextjs.org/) with App Router
- [React](https://reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Firebase](https://firebase.google.com/) (Authentication, Firestore, Storage)
- [shadcn/ui](https://ui.shadcn.com/) for UI components
- [Vercel](https://vercel.com/) for deployment
